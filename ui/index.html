      What's new

      About DiskWorks

      DiskWorks shows the disks in this computer the way Windows Disk Management does and lets you change them with the detailed options of GParted — on Windows, Linux and macOS, from one window.

      Disks

      Every disk is a bar, every partition a segment, unallocated space is hatched. Select something to see its details. Queue changes (create, delete, format, resize, label, drive letter, table type) and press Apply; nothing touches the disk before that. The exact commands are always one click away.

      Image

      Write an ISO or image file to a USB stick (Rufus-style), back up a disk or a partition to a compressed image, restore it later, and verify what was written.

      Access

      When this computer cannot open a partition by itself (for example ext4 on Windows), DiskWorks works through the ways to make it readable and writable and tells you which one it used.

      Speed

      Measures how fast a drive really writes and reads, with the cache switched off, and tells you which video formats it can sustain.

      Space

      Shows what fills a drive as rings you can click into, and lets you move files to the Recycle Bin / Trash or delete them.

      Log

      Every command the app ran, with its output.

      Administrator rights

      Looking never needs them. The first change asks once (Windows UAC / Linux password / macOS administrator prompt) and starts a small helper process that does the privileged work for the rest of the session. The window itself never runs as administrator.

      Version . Everything is bundled; nothing is downloaded at run time.
