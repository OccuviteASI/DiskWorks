# DiskWorks requirements ledger

One row per requirement. Statuses: **planned**, **done vX.Y.Z**, **deferred**,
**dropped**, **decision** (a design choice recorded so it is not re-litigated).
"Source" is who asked and when; "derived" means it follows from an ask or from the
research done on 2026-09-11 (sources in `ARCHITECTURE.md`). "Verified" says how it was
checked once done. Add a row for every new ask, including things deliberately not
done. Update statuses in the same pass as `CHANGELOG.md` and the `VERSION` bump.

Kenton's asks, 2026-09-11 (the origin of every R- row below):

1. An app that formats or resizes a drive or partition without the command line,
   for Windows and Linux, showing drive information like Disk Management but with the
   granular options of GParted, reading the primary Windows and Linux filesystems,
   and — when the OS cannot mount one of them — working out how to make it readable
   and writable from the OS.
2. Rufus-like imaging: write a drive from an ISO or other image file, and pull a
   backup image from a drive.
3. A version number shown in the app; clicking it shows that version's release notes.
4. Decisions taken when asked: name **DiskWorks**; the full foreign-filesystem
   ladder including offers to install open-source drivers; Linux tools **bundled** in
   the binary; first-release imaging = dd-mode writing + Windows install ISO mode +
   backup/restore (used-blocks-only backups later).
5. 0.1.1 (2026-09-11): right-click a partition **or a disk** for its options; keep the
   buttons but make them visible; do not stack the detail pane in a narrow column; never
   offer a partition size larger than fits; hide system drives behind a checkbox.
6. 0.2.0 (2026-09-11): a lock / unlock icon next to the Unlock button; make it buildable on
   a Mac (Apple Silicon) with build instructions; a slider to resize a partition over empty
   space (decided: drag the partition's edge on the disk bars); Mac ⇄ Windows/Linux
   partition access both ways (decided: bundled open-source read-only where it exists,
   commercial drivers named with their website, nothing installed); a disk speed test tab
   like Blackmagic Disk Speed Test; a drive-usage tab with file deletion like DaisyDisk.
