DiskWorks for macOS (Apple Silicon)
===================================

A. Use the ready-made app
-------------------------
1. Unzip DiskWorks-<version>-mac-arm64.zip (double-click it).
2. Move DiskWorks.app to Applications.
3. The app is not signed by Apple, so the first time macOS blocks it. Either
   - right-click DiskWorks.app > Open > Open, or
   - in Terminal:  xattr -dr com.apple.quarantine /Applications/DiskWorks.app
4. Optional extras (DiskWorks uses them when present, never installs them):
     brew install smartmontools     Drive health (S.M.A.R.T.) details
     brew install 7zip              read-only browser for ext4 / btrfs / NTFS
   The first time you touch an external disk macOS asks for "Removable Volumes"
   access; allow it. Internal disks may need Full Disk Access (System Settings >
   Privacy & Security > Full Disk Access > add DiskWorks).

B. Build it yourself on a Mac
-----------------------------
1. Install the Apple command-line tools once:   xcode-select --install
2. Install Python 3.12 or newer (3.14 recommended; .img.zst backups need 3.14):
     brew install python@3.14        (or the installer from python.org)
3. Get the source, either
     git clone https://github.com/OccuviteASI/DiskWorks.git && cd DiskWorks
   or unzip DiskWorks-src-<version>.zip from dist/mac-arm64/ and cd into DiskWorks.
4. Build:
     PYTHON=python3.14 ./build-mac.sh
   (creates .venv, installs the dependencies, runs build.py)
5. Result:
     dist/mac-arm64/DiskWorks.app
     dist/mac-arm64/DiskWorks-<version>-mac-arm64.zip
   Open it with:   open dist/mac-arm64/DiskWorks.app

Problems and the full first-run checklist: MACOS.md in the source.
